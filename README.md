# ConnectGram Social Media Application

A simple social media web application built using **Flask, SQLite, HTML, and CSS**.

The application provides basic social networking features such as user registration, login, posts, likes, comments, following users, and private messaging.

## Features

- User registration and login
- User profiles with username, email, and bio
- Create posts with captions and image URLs
- View posts in a feed
- Like and unlike posts
- Add comments to posts
- Follow and unfollow users
- Send messages to other users
- View conversations
- SQLite database for storing application data

## Technologies Used

- **Python**
- **Flask**
- **SQLite**
- **HTML**
- **CSS**
- **Flask-CORS**
